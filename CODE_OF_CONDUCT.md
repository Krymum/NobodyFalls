# Code of conduct

NobodyFalls is a game about holding each other up. We expect the same of the
people who build it.

This project follows the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
In short:

- Be kind and patient. Assume good faith; criticise ideas, not people.
- Welcome newcomers and questions. Everyone was new once.
- No harassment, insults, discrimination, sexualised content, or publishing
  someone's private information.
- Disagreement is fine; contempt is not.

It applies in issues, pull requests, discussions, and anywhere you represent the
project.

## Reporting

If someone's behaviour is a problem, contact the maintainer privately on GitHub
([Krymum](https://github.com/Krymum)) or use the private reporting described in
[SECURITY.md](SECURITY.md). Reports are kept confidential. The maintainer may
remove content, warn, or ban, following the Contributor Covenant's enforcement
guidelines.
